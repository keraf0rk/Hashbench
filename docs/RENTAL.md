## 🌈 Радужные таблицы

Способ разменять **вычисления на память**. Вместо хранения всех пар «хеш → пароль» (петабайты) хранят только **цепочки**: пароль → хеш → функция редукции → новый пароль → хеш → … тысячи шагов, а в таблицу пишут лишь **начало и конец**. Промежуточные значения пересчитываются на лету. «Радужные» — потому что на каждом шаге своя функция редукции (разные «цвета»), это убирает слипание цепочек.

**Почему сегодня почти мертвы:**

| Причина | Суть |
|---------|------|
| 🧂 Соль | таблица считается под функцию без соли; солёный хеш требует отдельной таблицы под каждую соль |
| ⚡ GPU-брутфорс | 7 млрд NTLM/с проще, чем качать и хранить многогигабайтные таблицы |
| 🐌 Медленные хеши | против sha256crypt/scrypt/Argon2 бессмысленны (соль + память + итерации) |

**Где ещё живы:** только старые несолёные быстрые хеши (NTLM, LM). Инструмент — RainbowCrack. На практике даже тут чаще берут hashcat-маской.

## 🔧 Как запускается

```
1. Взять инстанс с GPU (Docker-образ с CUDA/драйверами «из коробки»)
2. Подключиться по SSH
3. apt install -y hashcat   # или образ, где он уже есть
4. hashcat -I               # проверить, что видит GPU через CUDA
5. Залить свой hashes.txt + словари (scp/rsync)
6. hashcat -m <mode> -a 0 hashes.txt rockyou.txt -r rules/best64.rule
7. Забрать результат → ПОГАСИТЬ инстанс (биллинг посекундный!)
```

**Масштабирование:** нода 8× 4090 (~$2.5–3.5/час) даёт ×256 от M4 — hashcat раскидывает нагрузку по картам линейно.

> **Финальный вывод:** аренда делает **compute-hard** хеши уязвимыми за деньги, но против **memory-hard** (scrypt/Argon2) не спасает никакой бюджет. Отсюда и рекомендация хранить пароли в Argon2id.
